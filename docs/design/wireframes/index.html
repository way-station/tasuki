MVP ワイヤーフレーム / MVP wireframes

Issue #148. Each page draws the screens of docs/design/screens.md at phone width (390 px), with the values of docs/design/ui.md and the references of docs/design/ui-references.md. Open the files in a browser. The screen text is Japanese; the notes under each screen say what differs by role and what is not drawn.

docs/design/screens.md の画面を、スマートフォンの幅（390 px）で描いた。値は docs/design/ui.md、構成は docs/design/ui-references.md に従う。ブラウザで開いて見る。各画面の下の注に、幹事とメンバーで違うところと、絵にしていないことを書いた。
